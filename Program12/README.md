# P12 – Portfolio Projects Grid with Advanced CSS Grid

### Aim
To create a portfolio projects section using advanced CSS Grid properties to arrange project cards in a structured and responsive layout.

### Procedure

**HTML Elements Used:**
1. `<html>` – Defines the HTML document.
2. `<head>` – Contains page information and links the CSS file.
3. `<body>` – Contains all visible webpage content.
4. `<header>` – Displays the heading of the projects section.
5. `<main>` – Contains the main project content.
6. `<section>` – Groups the project cards.
7. `<div>` – Creates individual project cards.
8. `<img>` – Displays project images.
9. `<h1>` and `<h3>` – Display headings and project titles.
10. `<p>` – Displays project descriptions.
11. `<a>` – Provides links to project details.
12. `<footer>` – Displays footer information.

**CSS Properties Used:**
1. `display: grid` – Enables CSS Grid layout.
2. `grid-template-columns` – Defines the number and size of columns.
3. `gap` – Adds spacing between grid items.
4. `grid-column` – Controls how many columns an item occupies.
5. `grid-row` – Controls how many rows an item occupies.
6. `grid-template-rows` – Defines the height of grid rows.
7. `padding` – Adds space inside elements.
8. `margin` – Adds space outside elements.
9. `border-radius` – Rounds the corners of project cards.
10. `box-shadow` – Adds shadow effects
