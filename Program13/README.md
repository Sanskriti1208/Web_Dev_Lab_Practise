# P13 – Choosing Between Flexbox and Grid for a Shared Layout

### Aim
To understand and implement CSS Flexbox and CSS Grid together to create a structured and responsive portfolio webpage.

### Procedure

**HTML Elements Used:**
1. `<html>` – Defines the HTML document.
2. `<head>` – Contains webpage information and the CSS file link.
3. `<body>` – Contains the visible webpage content.
4. `<header>` – Creates the navigation header.
5. `<nav>` – Contains navigation links.
6. `<main>` – Contains the main webpage content.
7. `<section>` – Groups related content.
8. `<div>` – Creates individual project cards.
9. `<h1>` and `<h3>` – Display headings and project titles.
10. `<p>` – Displays descriptions.
11. `<a>` – Creates navigation links.
12. `<footer>` – Displays footer information.

**CSS Properties Used:**
1. `display: flex` – Enables Flexbox layout.
2. `justify-content` – Aligns items along the main axis.
3. `align-items` – Aligns items along the cross axis.
4. `flex-direction` – Sets the direction of flex items.
5. `flex-wrap` – Allows flex items to move to the next line.
6. `display: grid` – Enables CSS Grid layout.
7. `grid-template-columns` – Defines the number and size of columns.
8. `gap` – Adds spacing between elements.
9. `padding` – Adds inner spacing.
10. `margin` – Adds outer spacing.
11. `border-radius` – Rounds the corners of cards.
12. `box-shadow` – Adds shadow effects.
13. `@media` – Makes the webpage responsive.

### Observation
Flexbox is used to arrange navigation elements in a single direction, while CSS Grid is used to arrange project cards in rows and columns. Both layout techniques work together to create a responsive webpage.

### Result
A responsive portfolio webpage was successfully created using both CSS Flexbox and CSS Grid.
