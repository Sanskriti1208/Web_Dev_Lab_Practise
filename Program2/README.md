P2: Portfolio Repository with an Initial Commit
Aim: To create a Git repository for a portfolio project and record the initial changes through a commit.

Procedure:
1. Created a new project folder named portfolio.
2. Navigated into the project directory.
3. Initialized a Git repository using git init.
4. Created an HTML file named index.html.
5. Added HTML content to the file to create a basic portfolio webpage.
6. Checked the repository status using git status.
7. Added index.html to the staging area using git add index.html.
8. Committed the changes using git commit -m "Initial portfolio commit".
9. Verified the commit history using git log --oneline.

Result: Successfully created and initialized a local Git repository, added a basic HTML portfolio page, and recorded the initial commit.
