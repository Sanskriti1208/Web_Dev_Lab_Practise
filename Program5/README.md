# P5 – Semantic Bio Page

## 1. Aim
To design a personal bio webpage using semantic HTML elements and basic CSS styling to display personal information in a structured and visually appealing manner.

## 2. Procedure

1. Create an HTML file named `bio.html`.
2. Start with the basic HTML document structure using `<!DOCTYPE html>`, `<html>`, `<head>` and `<body>` tags.
3. Add a `<title>` tag inside the `<head>` section to set the webpage title.
4. Use the `<style>` tag to apply CSS styling to the webpage.

### HTML Elements and Tags Used

- **`<header>`:** Defines the introductory section of the webpage containing the name and a short description.
- **`<main>`:** Contains the main content of the webpage.
- **`<section>`:** Divides the main content into different sections.
- **`<h1>`:** Defines the main heading of the page.
- **`<h2>`:** Defines the subheadings for different sections.
- **`<p>`:** Displays paragraphs and personal information.
- **`<ul>`:** Creates an unordered (bulleted) list of hobbies.
- **`<li>`:** Defines individual items in the list.
- **`<footer>`:** Defines the bottom section of the webpage containing copyright information.

### CSS Properties Used

- **`background-color`:** Sets the background colour of elements.
- **`color`:** Changes the text colour.
- **`font-family`:** Specifies the font style.
- **`text-align`:** Aligns text to the centre.
- **`padding`:** Adds space inside elements.
- **`margin`:** Adds space outside elements.
- **`max-width`:** Sets the maximum width of the main content.
- **`border-radius`:** Creates rounded corners.

5. Add personal information under different sections such as About Me, Education, My Hobbies and Contact Me.
6. Apply CSS styling to improve the appearance and readability of the webpage.
7. Save the file and open it in a web browser to view the final output.

## 3. Observation

- The webpage is divided into meaningful sections using semantic HTML elements.
- Personal information is displayed in a structured format.
- CSS properties improve the layout, spacing, colours and overall appearance.
- The use of semantic tags makes the HTML code easier to read and understand.

## 4. Result

A personal bio webpage was successfully created using semantic HTML elements and basic CSS styling.
